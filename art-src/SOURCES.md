# art-src sources

Vendored source art for `tools/art.js` (it reads only this folder). Every file is a byte-for-byte copy of a pack download retrieved 2026-10-21 (fonts: 2026-10-23; DawnLike `Reptile0/1.png` and `Items/Music.png`: 2026-10-24, from DawnLike_5.zip, whose other files match the vendored hashes); licences were checked on each author's page that day and against the licence file inside the pack where one exists. Only the sheets referenced by `tools/art-manifest.js` (fonts: the `FONTS` list in `tools/art.js`) plus each pack's README or licence file are kept; the build output is `src/art/*.js` and `src/art/fonts.css`.

Fonts (`fonts/`): `tools/art.js` re-grids each font so 1 em = 16 font pixels (unitsPerEm rewritten; outlines untouched), sets one set of vertical metrics (hhea = OS/2 typo = win, whole font pixels, no line gap) and packs it as WOFF 1.0. Credits: Pixel Operator by Jayvee Enaguas (CC0, courtesy credit).
