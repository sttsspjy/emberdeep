# Wickdeep — Masterplan

North-star: a co-op browser survivors-like (solo or up to 4 friends, zero install) where a good run turns the screen into a blender. Rules and numbers: [GAME-DESIGN.md](GAME-DESIGN.md). Code contract: [ARCHITECTURE.md](ARCHITECTURE.md). The old dungeon game is kept at git tag `legacy-wickdeep`.

## Survivors rebuild
- [x] Foundation: arena, horde, spawner, 2 full hero weapons (Knight, Ranger), level-up cards, Camp shop, save code
- [ ] Renderer and juice: WebGL batcher, hit effects, screen shake, damage numbers
- [ ] Horde, stages and timelines: special foe brains, events, three stages
- [ ] 12 general weapons and their evolutions
- [ ] 7 heroes with signature weapons, Q and E skills
- [ ] 9 bosses (3 per stage)
- [ ] Co-op over the internet (host runs the game, friends join with a code)
- [ ] HUD, menus, results screen, unlocks
- [ ] Music and sound
- [ ] Balance pass and first playtest
