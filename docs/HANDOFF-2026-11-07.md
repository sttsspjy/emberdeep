# Handoff 2026-11-07

Mobile port shipped (branch `feat/mobile`). State and rules: [MOBILE-PLAN.md](MOBILE-PLAN.md), GAME-DESIGN §3 (auto aim).

## Mechanism
- Auto aim: sim-side, `p.in.auto` (input `ed` bit 11, level flag; NET_VERSION 15). `W.aimDir` reads the firing def's `autoAim` via `w.aimWs` set in `updateWeapons`; Q uses the skill def's `autoAim` through `W.autoPoint`. Bench: `--aim cursor|auto`.
- Touch: `src/client/touch.js` (stick + buttons, merged in `ED.Input.read`), `I.device 'touch'`, `html[data-dev]`, `html.aim-off`. Settings `aim`, `touchSize`.
- Layout: `@media (max-height: 500px)` blocks in style.css; `#ov-rotate` pure CSS.
- Render: coarse pointer → post canvas 1 px per world px; quality default `auto` (`R.autoQuality`, bloom off when first-run median frame > 22 ms).
- PWA: `sw.js` precaches index.html's file set, background all-or-nothing update, `src/client/pwa.js` reloads only on the title. Share / Invite / `#join=CODE`: `src/client/share.js`.
